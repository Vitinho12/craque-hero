# Craque Hero ⚽🏆
Um jogo de futebol estilo **Endless Runner Arcade** inspirado no clássico **Touchdown Hero**, com controle 2D livre, fintas, câmera lenta (slow-mo), zagueiros com IA de perseguição e disputa de pênalti emocionante!

![Mobile First](https://img.shields.io/badge/Suporte-Mobile%20%26%20Desktop-orange?style=for-the-badge)

## 🎮 Como Jogar
- **No Celular**: Toque e arraste o dedo livremente pela tela para conduzir a bola em qualquer direção (frente, trás, laterais). Segure para ativar o **Slow-Motion** e encontrar brechas na zaga!
- **No Computador**: Use o mouse para arrastar ou as teclas **W, A, S, D / Setas**.
- **Giro Especial (Spin Move)**: Toque no botão de giro ou aperte **Espaço / Shift** para aplicar um drible de 360° invulnerável!
- **Aos 1.000m (Pênalti Real)**: O jogador para na marca da cal cara a cara com o goleiro. Mire nos cantos, ajuste o ângulo e chute com precisão para estufar as redes!

## 🚀 Como Executar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno!
